### 打者
- 形は、ユーザーが出した横からの絵の構えです。胸をこちら(本塁)へ向け、顔は投手へ向けます。両手は後ろの肩の前・胸の高さ、両ひじは下げ、バットは頭の後ろに斜めに立て、ひざを曲げて広めに立ちます。前の腕にはエルボーガードを付けました。約6.5頭身です。
- **打った瞬間・振り切りは背中が見える形**です(11/2 ユーザーの絵と「打ったときは背中が見える」に合わせた)。腰が回って背中がこちらを向き、打った瞬間は体を本塁のほうへ倒して両腕を前へ伸ばし、振り切りはバットを後ろの肩の上へ回します。背中には背番号を大きく入れます(反転しない)。
- 構えは3通りで、能力から決めます(案A。11/2 ユーザー決定)。
  - 長打が得意(パワー75以上で、ミートより5以上高い)=**寝かせ**
  - ミートが得意(ミート75以上で、パワーより5以上高い)=**神主ふう**
  - ほか=**ふつう**
  - 1年目のリーグで測った割合(1軍とベンチの野手204人):ふつう 56%・神主ふう 21%・寝かせ 23%。
  - 乱数は使いません。スイングの姿勢は3通りとも同じです。
- 色:ヘルメットは打者の球団の色(`teamColorMap`)です。
  - ホームのユニフォームは白(アンダーシャツと文字は球団の色)。
  - ビジターは球団の色(11/2 ユーザー決定)。ただし「チームによっては灰色」の言葉に合わせて、**球団名のハッシュで4つに1つ**(`forteHash(名前+"ビジター")>>>3`)と、明るい色の球団は灰色にしました(割合は変えられます)。
- 番号:選手の背番号(`p.no`)を、構えでは**胸**に小さく、打った瞬間と振り切りでは**背中**に大きく入れました。背中の名前は出しません(構えで胸が見える向きにしたときにユーザー了承)。番号が無いとき(打席の情報が取れないときなど)は省きます。右打者は絵を反転しますが、番号は反転の外に置いたので鏡文字になりません。
- 肌:似顔(`FACE`)と同じ決め方です。`p.faceSeed||p.name` → `FACE.hash` → 同じ数列の最初の値で決まり、似顔の肌の明るいほうの色になります。

### 投手
- 捕手から見て正面の形で、顔は描きません。帽子とユニフォームは投手の球団の色で、ホーム/ビジターは打者と同じ決まりです。
- セット → 脚上げ → リリース → セット と動きます。
- リリースの手は `bcvStart` と同じ (143,110) です。左投げは反転し、(157,110) になります。
