# hl3d-billboard:3D の選手を「2D の絵の板(ビルボード)」に替える

元にした版:`src/pennant_source.html`(v2.2.l/BASE_V1 v1.8.b)。`APP_VERSION` は変えていない。

## 使い方

```bash
python3 work/hl3d-billboard/patch_hl3d-billboard.py src/pennant_source.html out.html
```

- パッチは `rep(old,new)` の並び。`old` が 1 回だけ見つかることを確かめながら当てる(見つからない・2 回以上なら止まる)
- テスト(リポジトリの一番上で回す):

```bash
python3 work/hl3d-billboard/bb_check.py file:///…/out.html file:///…/pennant_source.html $PWD/vendor/three-0.128.0.min.js <撮る先>
```

## 何を変えたか(関数名)

絵の部分(`hl3d*` の層)だけ。試合の計算・乱数・セーブ・2.5D の絵・球場・カメラ(`HL3D_CAMS`)には触っていない。

| 場所 | 変えたこと |
|---|---|
| `hl3dGeo` | 板の形 `"bill"`(幅 8・高さ 16、足元が原点)を足した |
| 新 `hl3dBillTex(U,role,pose,glv)` | 人の絵を Canvas 2D で描く(128×256。2.5 頭身・右向きの 3/4)。脚 2 本(ズボン=胴の色、膝下はベルトの色のストッキング、靴)・胴(ユニフォーム、襟、ベルト)・腕 2 本(袖の色、手は肌)・頭(肌は `hl3dUniform` の skin、耳・髪、目・眉・口・ほお)・帽子とつば。野手はグラブ、打者は立つ絵でバットをかつぐ。色と柄は `hl3dUniform` の結果をそのまま使い、縦縞・胸の帯は `U.tex`(`hl3dUniTex` の絵)を模様にして塗る。絵は「ユニフォームの色×型×姿勢×グラブ×バット」で使い回す(`hl3dBillC`。160 枚を超えたら古いものから捨てる) |
| 新 `hl3dBill(own,glv,uni,role,o)` | 選手の板。足元の丸い影と役割のリング(打者=赤・走者=黄)は今のまま地面に寝かせ、絵の板だけを子の `pv` に入れる。透明は `alphaTest .4` で切り、深さも書く(重なっても描く順が崩れない)。`userData.arm/glv/mats/op` は今と同じ形で持つ(消えるときの薄め・`hl3d_pose.py` が読む腕の角度) |
| 新 `hl3dBillFace(m,cam,dir,dv)` | 板をカメラへ向ける。横はカメラへ、上下はカメラの見下ろしの 7 割だけ倒す(見本と同じ)。向き `dir` がカメラから見て左なら左右反転(`scale.x=−1`。はっきり左右のときだけ切り替えるので、正面向きでパタパタしない)。飛びつき `dv` は向きの側へ倒す |
| 新 `hl3dBillPose`・`hl3dBillPoseOf`・`hl3dBillAct` | 姿勢の絵を替える。捕る・投げる(台本の `it.poses`。`hl3dArm` と同じ時刻)と飛びつき → 投げる/捕る、走る速さ → 走る 2 コマ(移動の位相 `it.ph` で交互)、捕手は打つ前 → しゃがむ、ほか → 立つ |
| `hl3dStart0` | 人を `hl3dBill` に。球場の人(ベンチ)の板を `S.bills` に集める。最後まで作れたら名前の札(`.hl3tag`)を外す(途中で失敗したときは札ごと 2.5D に戻る) |
| `hl3dUpdate` | 向き(`rotation.y`)を回す代わりに `it.fd` に覚えて左右反転に使う。姿勢の絵を選び、板をカメラへ向ける。`S.bills` もカメラへ向ける。**位置・時刻・腕の角度の計算は元のまま** |
| `hl3dParkMeshes` | 待つ打者(バットを持つ・リングなし)・ブルペンの投手と捕手(ファウルゾーン型・フェンス裏型。捕手はしゃがむ)・ベンチの選手(しゃがむ・.6 倍・床 −2.4。頭は屋根 4.6 の下)を板に。`userData.k`(pen・ondeck。ベンチは bench を足した)は今のまま |
| `hl3dBgBuild`・`hl3dBgDraw` | 背景の野手 7 人と捕手(しゃがむ)を板に。全部の板を `hl3dBgS.bills` に集め、毎コマカメラへ向ける。ブルペンの投手は「投げる」と「立つ」を 2.8 秒ごとに繰り返す(人ごとに時刻をずらす) |

- `hl3dMan` は**どこからも呼ばなくなった**(`grep -n "hl3dMan(" ` で出るのは定義の 1 行だけ)。定義を残したのは `tests_v2xx/hl3d_bg.py` の ⑳ が直接呼んで型を調べているため(消すと ⑳ が動かない)。要らなければ次の版で消してよい
- `hl3Declutter` は変えていない。札のない人の `.hl3bb` は今の「札がなければ飛ばす」(`if(!t) return;`)で飛ぶので、3D では得点の +N だけを並べ直す。エラーなし(bb_check で直接呼んで確かめた)
- 作る・描く所は全部 `hl3dNR` の中(観戦の `hl3dStart`・コマ、背景の `hl3dBgBuild`・`hl3dBgFrame`)。絵の CanvasTexture もさらに `hl3dNR` で包んだ

## 迷った所(決まり 8)

### 名前の札を消す方法

- A(王道):3D の舞台ができたら `.hl3tag` を DOM から外す ← **これで作った**
- B(尖った案):札を頭の上の小さな吹き出しにして、打者・走者だけ出す
- C(簡単):CSS で `display:none`
- C は今の `hl3d_shots.py` などが「隠れた札の位置(0,0)」をはみ出しと数えてしまうので A にした。A は札ごと 2.5D に戻す道(途中で失敗したとき)を壊さないよう、`hl3dStart0` の最後で外す

### 「投げる/捕る」の絵に替える時刻

- A(王道):台本の `it.poses`(`hl3dArm` が使うのと同じ時刻の窓)から決める ← **これで作った**
- B:腕の角度(`q.a`・`q.l`)の値のしきい値で決める(見本のやり方。投げる途中の角度では切り替わらない所があった)
- C:ボールが近くにあるときだけ

## 直さなかったこと・決めてほしいこと

1. **`hl3d_bg.py` の ⑲**:上の通り、板になったので通らない。正本に入れるときにテストを直す(案:`men[0].userData.bill` があり、`hl3dBillTex` の絵の帽子の所の色が `teamColorMap` の色)
2. **`hl3dMan` の定義**:どこからも使わないが、`hl3d_bg.py` ⑳ のために残した。⑳ を `hl3dUniform` だけを見る形に直すなら消せる
3. **捕手の位置**:観戦の捕手は 2.5D の札をよけるための位置(本塁の右 22)のまま(位置のデータには触らない決まり)。札がなくなったので、本塁の真後ろに寄せてもよいか決めてほしい
4. **夜の球場の明るさ**:絵の板は光の当たり方を受けない材質(MeshBasic)なので、夜の背景では選手が少し明るく浮く。見やすさを優先してそのままにした。暗く合わせたいなら板の色を少し落とす(`pm.color`)
5. **背番号・顔の描き分け**:今は全員同じ顔(色はユニフォームの型で変わる)。選手ごとに変えるとセーブか名前のハッシュが要るので、今回はしていない
6. **ブランチ名**:指示は `task/hl3d-billboard` だが、このクラウドのセッションは決められたブランチ(`claude/hopeful-johnson-yym16n`)にしか送れないので、そちらに送った
